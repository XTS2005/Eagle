# Eagle 1.0.0

Eagle 1.0.0 moves the project from public beta to its first stable release. It
combines a more reliable Prepare flow, verified result reporting and a refined
interface while preserving the established Dynamic Island and Dock paths.

## Highlights

- Prepare validates device, build, cache and session state before reporting
  readiness.
- Result reporting avoids false **Applied** states when protected work does not
  complete.
- Dynamic Island and Dock keep their isolated, stable apply paths.
- Home, Aura Studio, Styles, Tweaks, shared controls and Wallpapers have a
  cleaner, more consistent presentation.
- The opening screen is now **Updates / Actualizaciones** with clear device and
  compatibility information.
- Icon Studio is temporarily marked **Coming soon**.
- Aura Tint is temporarily unavailable; Glow, Pulse and Island Rainbow remain
  available where compatible.

## Compatibility

- Supported: iOS 17.0–18.7.1 and iOS 26.0–26.0.1.
- Limited testing: iOS 16.7.2.
- Blocked for safety: unverified iOS 16 builds, iOS 18.7.2+, iOS 19–25,
  iOS 26.0.2+ and current MIE devices.
- Prepare is additionally blocked on iPhone 16 (`iPhone17,3`) running iOS 18.5
  following field reports of full device restarts.

Eagle is primarily verified on iPhone 16 Pro (`iPhone17,1`) running iOS 18.6.2
(`22G100`). Other supported device and OS combinations may still require
model-specific validation.

## Installation and safety

The attached `Eagle.ipa` is unsigned. Sign it using your usual personal-device
installation method. Back up important data, apply one feature at a time and
stop after any reboot, timeout or protected-call error.

Do not publish tokens, certificates, provisioning profiles or personal data in
bug reports.
