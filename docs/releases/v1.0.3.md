# Eagle 1.0.3 (62)

Eagle 1.0.3 introduces dedicated art galleries for Dynamic Island and Dock customization, synchronizes their verified state with Aura Studio, and refines the app's release presentation.

## New experiences

- **Island Gallery:** Starlight, Inferno, Horizon, Vortex, Bubblegum, and Traffic.
- **Dock Gallery:** Bubblegum, Springfield, and Bikini Bottom.
- Island artwork shares one verified geometry and uses a fixed halo based on each design's dominant color.
- Dock artwork is packaged at 1146 × 318 pixels, the exact @3x representation of Eagle's 382 × 106-point Dock frame.
- The system Dock background can be hidden or restored independently from the artwork and Dock icons.

## Reliability and interface

- Dock Gallery and Aura Studio clear or replace each other's active metadata accurately.
- Expired SpringBoard sessions no longer keep a Gallery style marked active.
- Supported TrollStore installations can reuse existing mobile-filesystem access without an unnecessary sandbox transition.
- Gallery cards provide color-aware motion and honor Reduce Motion.
- Home, Passcode, wallpaper, diagnostics, and release-update presentation received localization and layout refinements.

## Verification

- Clean Release build and asset-catalog validation.
- Static analyzer completed successfully; remaining dead-store findings are confined to the unchanged diagnostic code in `RemoteCall.m`.
- Primary device: iPhone 16 Pro (`iPhone17,1`) on iOS 18.6.2 (`22G100`).
- Additional preparation validation: iPhone 14 Pro Max on iOS 17.0 using TrollStore.

The release IPA is unsigned. Users must sign it with their normal personal-device installation method.
