# Eagle 1.0.2 (61)

Eagle 1.0.2 is a focused interface and workflow update. It preserves the
verified Prepare, Dock and Dynamic Island Aura paths while making Aura Studio
clearer and correcting inherited open-source attribution.

## Changes

- Refined Eagle mark and wordmark with a restrained, accessible spectrum sheen.
- Cleaner adaptive contrast across Home, Access, navigation and Aura surfaces.
- Accurate Aura preview behavior: steady Glow, independent Pulse and
  Rainbow-only spectrum movement.
- Preview animation pauses when the selected mode does not animate.
- Independent system-Island hide/restore control with readback verification.
- Respring now/later choice after a verified system-Island preference change.
- Direct Stable, Advanced and Laboratory channel controls on Home, with an
  accurate warning before moving to a lower channel.
- Island Rainbow remains part of Stable; higher channels add their documented
  feature sets without changing device support.
- Wallpaper installs now report system-gallery refresh failures honestly and
  correctly identify catalog entries that require iOS 26.
- Cyanide/0xjohnny OTA attribution retained in source, README and app bundle.

## Preserved behavior

- Prepare and device compatibility policy are unchanged.
- Dock and Dynamic Island Aura apply/remove paths are unchanged.
- The verified iPhone 16 Pro (`iPhone17,1`) profile is unchanged.
- Icon Studio remains **Coming soon** and Aura Tint remains unavailable.
