# Eagle 0.3.0 Beta 1

This is the first public Eagle beta. It is provided so the community can test the current work and report reproducible problems while the project continues to improve.

## Included

- coordinated Styles for wallpapers, passcode themes and supported Wallet-card artwork;
- wallpaper browsing, package import and Pocket Poster video conversion;
- Wallet-card preview, apply, backup and restore;
- passcode theme browsing, import, preview and restore;
- experimental Icon Studio and Dock layouts;
- experimental Island Aura with native adaptive and compact fallback modes;
- Eagle System features, including Guardian checks, Scenes and shareable recipes;
- English and Spanish interface text.

## Read before installing

- This build has been tested primarily on **iPhone 16 Pro with iOS 18.6.2 (22G100)**.
- Support for other devices or iOS versions is not guaranteed.
- Kernel and SpringBoard operations can respring or reboot the device. Back up important data and test one feature at a time.
- The attached `Eagle.ipa` is **unsigned**. It contains no signing certificate or provisioning profile.
- Stop the Xcode debugging session before preparing Eagle access, then open Eagle manually from the Home Screen.

When reporting a problem, include the device model, exact iOS version and build, selected feature/mode, result message, and a screenshot or sanitized end of `Documents/lara.log` when relevant.
